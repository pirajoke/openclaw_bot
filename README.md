# openclaw_bot

Archived GitHub-to-Telegram notification experiment.

The repository contains only:

- a reusable Telegram notification workflow;
- a caller that applies it to issue and pull-request events in this same
  repository.

A portfolio-wide search on 2026-07-27 found no external repository consuming
the reusable workflow. Existing repository secrets are left untouched for
recovery.

workflow into the current orchestration stack.
